# Routers REST

Endpoints separados por dominio:

- autenticación;
- datasets;
- `/experiments`: compatibilidad con la API histórica de ejecuciones;
- `/runs`: API explícita de corridas;
- `/experiment-groups`: experimentos con múltiples corridas/datasets;
- `/parameter-presets`: parámetros avanzados y predefinidos;
- `/batches`: lotes de experimentos;
- recursos GPU y Acerca de.
