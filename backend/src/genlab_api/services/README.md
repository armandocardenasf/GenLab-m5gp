# Servicios del backend

- `gpu.py`: detección y reserva transaccional de GPUs.
- `files.py`: almacenamiento seguro y validación de datasets.
- `experiments.py`: lanzamiento/cancelación de una ejecución histórica.
- `lab.py`: perfiles, materialización de corridas, cola, agregación global y por dataset, nube de puntos y serialización de experimentos/lotes.
